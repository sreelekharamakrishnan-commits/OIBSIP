# ATM Interface

## OASIS INFOBYTE - Java Development Internship

### Task 3 - ATM Interface

## Project Description

This project is a console-based ATM Interface developed using Java.
It simulates basic ATM operations such as user authentication,
withdrawal, deposit, fund transfer, and transaction history.

## Features

- User ID and PIN authentication
- Maximum 3 incorrect login attempts
- Transaction History
- Withdraw money
- Deposit money
- Transfer money to another account
- Balance validation
- Current balance display
- Object-Oriented Java design using multiple classes

## Technologies Used

- Java
- VS Code
- Console Application
- Object-Oriented Programming

## Project Structure

- Main.java - Starts the ATM application
- ATM.java - Handles ATM operations and menu
- Bank.java - Manages bank accounts
- Account.java - Stores account details and balance
- Transaction.java - Stores transaction information
