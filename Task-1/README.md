# Number Guessing Game

## Project Overview

Number Guessing Game is a console-based Java application in which the
computer generates a random number and the player tries to guess it within
a limited number of attempts.

The game provides hints such as "Too High!" and "Too Low!" to help the
player guess the correct number.

## Objective

The objective of this project is to develop a simple interactive game using
Java and demonstrate basic programming concepts such as loops, conditions,
random number generation, user input, and score tracking.

## Technologies Used

- Java
- Scanner
- Random
- ArrayList

## Features

- Random number generation
- Three difficulty levels
- Too High and Too Low hints
- Limited number of attempts
- Correct answer detection
- Play Again option
- Score tracking
- Invalid input handling

## Difficulty Levels

| Level | Range | Attempts |
|---|---|---|
| Easy | 1-50 | 10 |
| Medium | 1-100 | 7 |
| Hard | 1-200 | 5 |

## How to Play

1. Start the program.
2. Select a difficulty level.
3. Enter your guess.
4. The game will tell you whether your guess is Too High or Too Low.
5. Continue guessing until you find the correct number.
6. If you use all attempts, you lose the round.
7. Choose whether you want to play again.
8. At the end, the game displays the score summary.

## How to Run

Compile the program:

javac NumberGuessingGame.java

Run the program:

java NumberGuessingGame
